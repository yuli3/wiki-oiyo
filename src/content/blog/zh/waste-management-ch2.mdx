# 韩国生活垃圾分类与资源循环 — 第2章: 透明PET塑料瓶单独投放标准

韩国环境部从2020年12月起在公寓小区、2021年12月起在全国独栋住宅全面实施**透明PET瓶单独投放制度**。过去所有塑料一起投放，现在无色透明的饮用水、饮料PET瓶必须与一般塑料严格分开，投入专用回收箱。

看起来只是多了一个分类项目，但这项制度背后是高分子化学和回收产业供应链的变化。

---

## 1. 长丝（服装用纱线）与短纤维的区别

在过去的混合回收中，透明PET瓶与有色PET瓶（绿色汽水瓶、棕色啤酒瓶）、复合材质（OTHER）以及杂物混在一起回收。这样的瓶子即使粉碎成再生瓶片，颜色也不均匀、性能下降，主要只能**降级回收**为填充棉、绳子、无纺布等低档**短纤维**。

相反，没有杂质的无色透明PET瓶经过高纯度提纯后，可以加工成**长丝（filament）**。长丝是能织成服装、户外服、包袋和跑鞋鞋面的高附加值纱线，最终还能再做成PET瓶，形成**瓶到瓶（bottle-to-bottle）**的闭环。

```
[混合回收的PET瓶] ───> 低纯度瓶片 ───> 无纺布/蛋托/绳子（短纤维：再生有限）
[单独回收透明PET瓶] ───> 高纯度再生颗粒 ───> 服装/鞋/再生瓶（长丝与瓶到瓶）
```

透明PET瓶按环境部统一的四个步骤投放。

1. **倒空**：把内容物全部倒干净。
2. **冲洗**：用水轻轻冲洗瓶内，去掉饮料残留。
3. **撕掉标签**：沿虚线把塑料标签（多为PP或PS）完全撕下，作为塑料膜类另行投放。
4. **压扁并拧上瓶盖**：踩扁压平后，把瓶盖重新拧上再投放。

<Callout type="tip" title="瓶盖不是PET，为什么要拧上再扔？">
很多人以为瓶盖和瓶口环是聚乙烯（PE）或聚丙烯（PP）材质，应该单独扔掉。但**官方指南是拧上瓶盖投放**，原因有两个：
1. **保持压扁状态，防止污染**：拧上瓶盖能保持压缩后的体积，回收和分拣时沙子、杂物也进不去。
2. **水中比重分离**：回收工厂会把瓶身和瓶盖一起粉碎后放入水中。
   - PET的比重约为**1.3～1.4**，比水（1.0）重，会**沉底**。
   - 瓶盖（PE/PP）约为**0.90～0.95**，比水轻，会**浮起**。
   经过清洗槽的浮沉分选，瓶盖材质和瓶身材质大部分可以机械分开。
</Callout>

## 3. 不能投入透明PET瓶回收箱的物品

并非所有透明塑料容器都属于透明PET瓶。只有**装过饮用水或饮料的无色透明瓶**才符合。

| 物品 | 材质与特点 | 正确投放途径 |
|---|---|---|
| **透明的矿泉水、气泡水、饮料瓶** | 无色聚对苯二甲酸乙二醇酯（PET） | **透明PET瓶专用回收箱** |
| **一次性透明外带杯** | PS（聚苯乙烯）或混合等级PET | **一般塑料类** |
| **水果、沙拉透明包装盒** | 多为挤出成型片材（PET/OTHER） | **一般塑料类** |
| **透明调料瓶、酱油瓶、食用油瓶** | 油或浓调料渗入，无法洗净 | **一般塑料类（污染严重则投入计量袋）** |
| **有色PET瓶（绿色、棕色等）** | 添加染料的有色PET | **一般塑料类** |

## 小结

只要正确分类投放，透明PET瓶不用任何新的石油基原料，就能再生为顶级纱线。

关键是**撕掉标签**和**压扁后拧上瓶盖**。下一章（第3章）将从饲料化的角度，讲解家里最容易混淆的**厨余垃圾与一般垃圾的区分标准**。
