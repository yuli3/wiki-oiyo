## 2. Evolving problem practice (Step 9: the ultimate compound-inference boss)

**Question 6 (NCS/PSAT style)**: Given that all five of the following conditions are true, which conclusion must be true?

> 1. If A attends the meeting, B attends too.
> 2. Either B does not attend, or C attends.
> 3. If C does not attend, D attends.
> 4. If E attends, D does not attend.
> 5. A attended the meeting.

1. D attended and B did not attend.
2. Both B and C attended.
3. C attended and D did not attend.
4. A did not attend.

<Callout type="tip">
**[A master's thought process]**
1. **Symbolize**:
   - (1) A → B
   - (2) ~B ∨ C (converted: **B → C**)
   - (3) ~C → D
   - (4) E → ~D (contrapositive: **D → ~E**)
   - (5) **A (confirmed information!)**

2. **Chain it together**:
   - Start from the confirmed fact (5): **A(T)**.
   - By (1), A → B, so → **B(T)**.
   - By the converted form of (2), B → C, so → **C(T)**.

3. **Can the remaining propositions be pinned down?**
   - Since C is true, the antecedent (~C) of (3) "~C → D" is false → **whether D attends is unknown** (a false antecedent forces nothing in a conditional).
   - Since D is undetermined, (4) leaves **whether E attends unknown** as well.
   - In other words, the only thing that's **100% certain here is that A, B, and C all attended.**

4. **Check each option**:
   - ① Makes a claim about D and B → D is unknown, and B did attend anyway, so this is **false**.
   - ② **Both B and C attended** → confirmed above. **True!**
   - ③ Includes a claim about D → since D is unknown, this **can't be confirmed**.
   - ④ A did not attend → directly contradicts (5) → **false**.

**Answer: ② Both B and C attended.** (the one conclusion the chain of confirmed information forces)
</Callout>

## 3. Your final checklist before passing: "mistake prevention"

1. **Handling "or (∨)"**: Did you convert it into a conditional — "If not A, then B" — before slotting it into the chain?
2. **"Only if ~"**: Did you accidentally write the arrow backward? (A iff B)
3. **"Some" vs. "All"**: In a "Some" proposition, did you carelessly extend an arrow chain where you shouldn't have?
4. **Time management**: If you can't see the chain within a minute, did you immediately switch to **reductio ad absurdum (making an assumption)**?
