## 1. Origines : une ancienne carte secrète

L'origine exacte de l'ennéagramme reste mystérieuse. Des éléments de l'ancienne Babylone, du soufisme et de la spiritualité chrétienne se sont combinés avant d'être transmis à l'Occident par Gurdjieff. Ce n'est pas un simple test psychologique, mais une carte sacrée de l'intériorité humaine.

## 2. Les trois centrès de force (Center)

Chaque personne utilise principalement un centre d'énergie différent.

### ① Centre instinctif (types 8, 9, 1) - instinct / colère

- **Mots-clés :** autonomie, justice, survie.
- **Caractéristiques :** "C'est moi qui contrôle ma vie." Direct et attentif à la force. Sous stress, il se met en colère.

### ② Centre du cœur (types 2, 3, 4) - émotion / honte

- **Mots-clés :** relation, image, reconnaissance.
- **Caractéristiques :** "Comment les autres me voient-ils ?" Sensible aux réactions d'autrui. Il craint de ne pas être aimé.

### ③ Centre de la tête (types 5, 6, 7) - pensée / peur

- **Mots-clés :** sécurité, analyse, avenir.
- **Caractéristiques :** "Cette situation est-elle sûre ?" Il anticipe et se prépare. Pour éviter l'anxiété, il se réfugie dans la pensée ou poursuit le plaisir.

## 3. Les neuf types de personnalité

| Numéro | Surnom | Peur (ce qui est évité) | Désir (ce qui est recherché) |
| :---- | :--------- | :----------------- | :------------------------ |
| **1** | Réformateur | Le mal, les défauts, les erreurs | Intégrité, perfection |
| **2** | Aidant | Ne pas être aimé | Devenir nécessaire aux autres |
| **3** | Battant | L'échec, l'incompétence | Réussir, être respecté |
| **4** | Artiste | La banalité, le manque | Originalité, découverte de soi |
| **5** | Investigateur | L'incapacité, l'ignorance | Connaissance, compétence |
| **6** | Loyaliste | Le danger, l'absence de soutien | Sécurité, confiance |
| **7** | Enthousiaste | La douleur, la privation | Bonheur, satisfaction |
| **8** | Challenger | Être contrôlé, être faible | Initiative, force |
| **9** | Pacificateur | Le conflit, la séparation | Paix, stabilité |

## 4. Aile (Wing) et flèches (Direction)

Vous n'êtes pas un point fixe.

- **Aile :** vous utilisez l'un des deux nombres voisins comme arme secondaire. Par exemple, un type 1 avec une aile 9 devient un réformateur plus doux.
- **Intégration et stress :** lorsque vous êtes en bonne santé, vous utilisez les forces d'un certain type, l'intégration ; sous stress, les défauts d'un autre type surgissent, la désintégration. Comprendre ce flux permet de diagnostiquer son propre état psychique.

## 5. Pour conclure : sortir de la prison

Dire "je suis un type 4" et s'y coller une étiquette est un mauvais usage de l'ennéagramme.
Le but est de remarquer : "Ah, je suis encore enfermé dans la prison du type 4, avec sa mélancolie et son sentiment d'élection", puis d'en sortir. Le type n'est pas vous-même ; c'est l'armure que vous portez. Quand l'armure devient trop lourde, l'ennéagramme enseigne comment l'enlever.

### Questions fréquentes (FAQ)

**Q : Le type change-t-il ?**
A : On considère généralement que le type de base (Core Type) ne change pas au cours de la vie. En revanche, son expression varie énormément selon le niveau de maturité. Un type 8 sain peut être un grand leader ; un type 8 malsain peut devenir tyrannique.

**Q : Est-ce utile avec le MBTI ?**
A : Oui, beaucoup. Si le MBTI est l'ossature, la structure, l'ennéagramme est le sang qui y circule, la motivation. Par exemple, deux INFP peuvent différer fortement : le type 4 sera plus artistique, le type 9 plus pacifique.
