# Chapter 4. 帰謬法と場合の数 — 高難度問題への対処法

これまでに学んだ条件文、ド・モルガン、三段論法は「基本ツール」です。しかし実際の試験で困るのは、**「どこから始めればよいかわからない」**場合です。確定情報がないとき、上級者は2つの強力な武器を使います。

---

## 1. 帰謬法（背理法: Reductio ad Absurdum）

「結論が偽だと仮定すると矛盾が生じる → 結論は真」という推論法です。

**手順**:

1. **結論の否定を仮定**: 「結論が偽である」と仮定する
2. **推論を進める**: 前提と組み合わせて論理を展開する
3. **矛盾を発見**: 前提と矛盾する命題を導出する
4. **結論確定**: 矛盾が生じたので、元の結論が真であると確定

## 3. 実践問題

**問題 (帰謬法の応用)**: 犯人は甲・乙・丙・丁のうち1人である。次の4人の発言のうちただ1人だけが真であるとき、犯人は誰か？

> - 甲: 乙が犯人だ。
> - 乙: 丁が犯人だ。
> - 丙: 私は犯人ではない。
> - 丁: 乙の発言は嘘だ。

<Callout>
**解説 — 矛盾ペアを先に見つける**:

1. **甲が犯人だと仮定**: 甲(偽)、乙(偽)、丙(真)、丁(真) → 真が2人（矛盾！ただ1人だけが真のはず）
2. **乙が犯人だと仮定**: 甲(真)、乙(偽)、丙(真)、丁(真) → 真が3人（矛盾！）
3. **丙が犯人だと仮定**:
   - 甲「乙が犯人だ」は偽 (F)
   - 乙「丁が犯人だ」は偽 (F)
   - 丙「私は犯人ではない」は、丙自身が犯人なので偽 (F)
   - 丁「乙の発言は嘘だ」は、乙の発言が実際に嘘なので真 (T)
   - 真がちょうど1人 → **条件を満たす！**
4. **丁が犯人だと仮定**: 甲(偽)、乙(真)、丙(真)、丁(偽) → 真が2人（矛盾！）
5. **ポイント**: 乙と丁は矛盾関係にある（丁が乙の発言を正面から否定しているため、どちらか一方だけが必ず真）。したがって真である1人は必ず乙か丁のどちらかで、**甲と丙は必ず偽**。丙の発言「私は犯人ではない」が偽ということは、**丙が犯人**であることが確定する。

**結論**: 犯人は丙で、真の発言をしたのは丁である。
</Callout>

---

**問題 (場合の数の応用)**:

> - 条件1: AプロジェクトまたはBプロジェクトが推進される。
> - 条件2: BプロジェクトまたはCプロジェクトが推進される。
> - 条件3: AプロジェクトまたはDプロジェクトが推進される。

「Bプロジェクトが推進されない」場合、必ず推進されるものは？

<Callout>
**解説 — 場合の数分離**:

~Bが確定した場合:
- 条件1(A ∨ B)で~B → **Aが確定**
- 条件2(B ∨ C)で~B → **Cが確定**
- 条件3(A ∨ D): Aが既に確定 → DはあってもなくてもよいがAは確定

**結論**: A と C が必ず推進される。
</Callout>

## 4. 上達のためのInsight

帰謬法と場合の数分離は、**「確定情報がないときの最終兵器」**です。どこから始めればよいかわからないときは:

1. まず「確定している情報（断定命題）」を探す
2. なければ「選言の一方」を仮定して場合分けする
3. 矛盾が出たら帰謬法で反証する
