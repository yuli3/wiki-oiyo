# 韓国の生活ごみ分別と資源循環 — 第2章: 透明ペットボトルとプラスチック選別の実態

韓国環境部は2020年12月に共同住宅（アパート団地）から、2021年12月には全国の一戸建てまで**透明ペットボトルの分別排出制度**を全面的に実施しました。以前はすべてのプラスチックをまとめて出していましたが、現在は無色透明の水・飲料用ペットボトルを一般のプラスチック類と厳しく分け、専用の回収箱に出す必要があります。

分別項目が一つ増えただけに見えますが、この制度には高分子化学とリサイクル産業のサプライチェーンの仕組みが詰まっています。

---

## 1. 長繊維（衣料用の糸）と短繊維の違い

かつての混合回収では、透明ペットボトルが有色ペットボトル（緑のサイダーびん、茶色のビールボトル）や複合素材（OTHER）、異物と一緒に回収されていました。こうして混ざったボトルは、砕いて再生フレークにしても色がそろわず物性も落ちるため、主に綿・ひも・不織布といった低級な**短繊維（ステープル）**にしか**ダウンサイクル**できませんでした。

一方、不純物のない無色透明のペットボトルは、高純度の精製を経て**長繊維（フィラメント糸）**に加工できます。長繊維は衣類、アウトドアウェア、バッグ、ランニングシューズのアッパーなどを織れる高付加価値の糸で、最終的には再びペットボトルをつくる**ボトル to ボトル**の閉じた循環を実現します。

```
[混合回収のペットボトル] ───> 低純度フレーク ───> 不織布/卵トレー/ひも（短繊維：再生の限界）
[透明ペットボトルを分別] ───> 高純度再生ペレット ───> 衣類/靴/再生ボトル（長繊維・ボトル to ボトル）
```

透明ペットボトルは、環境部の共通の4ステップに従って出します。

1. **空にする**: 中身を残さず出します。
2. **すすぐ**: 水で内側を軽くすすぎ、飲み残しを洗い流します。
3. **ラベルをはがす**: ビニールラベル（多くはPPまたはPS）をミシン目に沿って完全にはがし、ビニール類として別に出します。
4. **つぶしてキャップを閉める**: 足で踏んで平らにつぶし、キャップを閉め直して出します。

<Callout type="tip" title="キャップはPETではないのに、なぜ閉めて出すの？">
キャップやリングはポリエチレン（PE）やポリプロピレン（PP）製なので別に捨てるべきだと考える人は多いですが、**キャップを閉めて出すのが公式の指針**です。理由は二つあります。
1. **つぶした形を保ち、汚れを防ぐ**: キャップを閉めておけば圧縮した体積が保たれ、回収・選別の途中で砂や異物が中に入りません。
2. **水中での比重分離**: リサイクル工場ではボトルとキャップを丸ごと細かく砕いて水に入れます。
   - PETの比重は約**1.3〜1.4**で、水（1.0）より重く**沈みます**。
   - キャップ（PE/PP）は約**0.90〜0.95**で、水より軽く**浮きます**。
   洗浄槽での浮沈選別で、キャップの素材とボトル本体の素材はほとんどが機械的に分かれます。
</Callout>

## 3. 透明ペットボトル回収箱に入れてはいけないもの

透明なプラスチック容器がすべて対象になるわけではありません。**「飲料水・飲み物」が入っていた無色透明のボトル**だけが対象です。

| 品目 | 素材と特徴 | 正しい出し方 |
|---|---|---|
| **透明な水・炭酸水・飲料ボトル** | 無色のポリエチレンテレフタレート（PET） | **透明ペットボトル専用回収箱** |
| **使い捨ての透明テイクアウトカップ** | PS（ポリスチレン）や混合グレードのPET | **一般プラスチック類** |
| **果物・サラダ用の透明トレー** | 主に押出成形のシート（PET/OTHER） | **一般プラスチック類** |
| **透明な調味料・しょうゆ・食用油の容器** | 油や濃い調味料がしみ込み洗い落とせない | **一般プラスチック類（汚れがひどければ従量制袋）** |
| **有色ペットボトル（緑・茶など）** | 染料を加えた有色PET | **一般プラスチック類** |

## まとめ

透明ペットボトルは、正しく分別されれば新しい石油系原料を使わずに最高級の糸へと生まれ変わる資源です。

ポイントは**ラベルをはがすこと**と**つぶしてキャップを閉めること**です。次の第3章では、家庭で最も迷いやすい**生ごみと一般ごみの見分け方**を、飼料化の観点から扱います。
