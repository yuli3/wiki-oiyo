**仕事の価値観（work values）**とは、仕事内容、環境、人間関係、報酬、自律性などのうち、何を大切にするかを示す基準です。興味が「何をしたいか」に近いのに対し、仕事の価値観は「どのような条件で働きたいか」に近い概念です。

仕事の価値観は、能力、適性、性格、資格を測るものではありません。ある価値が高くても、特定の職業に向いていることの証明にはなりません。キャリアを考えるための一つの資料として扱います。

## O*NET・CareerOneStopの6つの仕事価値

米国労働省のO*NETデータ体系とCareerOneStop Work Values Matcherは、次の6価値を用います。

| 価値 | 概要 |
|---|---|
| 達成（Achievement） | 能力を生かし、達成感を得られる仕事 |
| 独立性（Independence） | 自分で判断し、アイデアを試せる仕事 |
| 承認（Recognition） | 昇進、リーダーシップ、評価の機会がある仕事 |
| 関係（Relationships） | 人を助け、倫理的で良好な関係を築ける仕事 |
| 支援（Support） | 組織や管理者から公正な支援を得られる仕事 |
| 労働条件（Working Conditions） | 安定、報酬、安全、多様性など望ましい条件がある仕事 |

現在のCareerOneStop Work Values Matcherは、理想の仕事に関する**20の記述を重要度別に並べるカード分類**です。結果を6価値に結び付け、O*NET Work Importance Locator（WIL）を基礎としています。ただしO*NET WIL自体は**2024年6月3日に提供終了**となり、資料のみが研究・歴史目的で保管されています。

## OIYOの活動との違い

OIYOはセルフリフレクション用に、別の**18項目・6次元の活動**を独自に作成しています。

| 区分 | O*NET・CareerOneStop | OIYO |
|---|---|---|
| 次元 | 達成、独立性、承認、関係、支援、労働条件 | 安定性、達成、自律性、貢献、創造性、承認 |
| 形式 | CareerOneStopの20カード分類 | 18項目への回答 |
| 位置づけ | O*NETに基づく公的なキャリア探索枠組み | OIYO独自の振り返り活動 |

似た名称があっても、同じ尺度ではありません。OIYOの活動は公式O*NET WILではなく、心理測定上の妥当性検証や標準化を受けた検査として提示していません。両者の点数を換算したり、結果だけで職業適合を判断したりしないでください。
