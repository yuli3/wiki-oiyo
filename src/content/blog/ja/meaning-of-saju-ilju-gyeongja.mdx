庚子日柱は六十干支の37番目の干支であり、硬い鉄や原石である陽金の天干「庚」が、真夜中の知恵あるネズミである地支「子」の上に座した形です。真冬の冷水に浸して鍛えられる鉄 — 冷たく研ぎ澄まされる明晰さの象徴です。

## 一目でわかる庚子

| 区分 | 内容 |
|---|---|
| 漢字 | 庚子 |
| 構成 | 天干 庚（陽金） + 地支 子（子年、水） |
| 納音五行 | 壁上土 |
| 日支 十二運星 | 死 |
| 日支 十神（正気） | 傷官 |
| 該当年度 | 1960年 · 2020年 |
| キーワード | 明晰、批判、革新 |

## 性格と気質

庚子日柱は頭脳が非凡で、批判精神が強い革新家タイプです。傷官の鋭さで古いものを壊し、新しいものを築くことに長けています。

- **強み**: 非凡な頭脳と分析力、改革的な推進力。
- **注意点**: 毒舌が深い傷を残すことがあります。刃物は手術に使うとき最も価値を発揮します。

## 構造で読み解く — 命理的解釈

[庚日干](/ja/meaning-of-saju-stem-gyeong/)が [子地支](/ja/meaning-of-saju-branch-ja/)の上に座し、日支の正気を基準とした十神は [傷官](/ja/meaning-of-saju-god-sanggwan/)、十二運星は [死](/ja/meaning-of-saju-stage-sa/)に該当します。傷官は弁舌と創意の星であり、枠を壊す表現力が魅力であると同時に、口舌の種にもなります。「死」の座にあるため、一つの道を深く掘り下げる没入の構造を持っています。

納音五行では壁上土に属し、同じ納音を持つ干支と組み合わせて、古来の命理学で好んで用いられた分類です。
