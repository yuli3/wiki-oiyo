年末調整で勤務先に出す書類のうち、**計算が必要なのは「保険料控除申告書」**です。保険会社から届く控除証明書の金額を書き写し、欄ごとの式で控除額を出します。この章では4つの欄を順に見ていきます。

<Callout type="note" title="前提">
- 金額と計算式は国税庁タックスアンサー（No.1140・1145・1130・1135）と令和8年分の年末調整のしかたで確認しました（確認日 2026-11-03）。
- 23歳未満の扶養親族がいる場合の一般生命保険料の特例は[第2章](/ja/japan-year-end-adjustment-ch2/)で扱いました。この章は通常の計算を中心に書きます。
- Oiyoは国税庁と関係ありません。迷うときは勤務先の担当者か税務署に確認してください。
</Callout>

## 1. 生命保険料控除：新制度と旧制度で式が違う

保険の契約日が**平成24年（2012年）1月1日以後なら新制度**、それより前なら旧制度です。控除証明書に「新」「旧」の区分が書かれています。新制度は「一般」「介護医療」「個人年金」の3つ、旧制度は「一般」「個人年金」の2つに分けて計算します。

**新制度（1区分あたり）**

| 1年間の支払保険料 | 控除額 |
|---|---|
| 20,000円以下 | 全額 |
| 20,000円超 40,000円以下 | 支払額 × 1/2 ＋ 10,000円 |
| 40,000円超 80,000円以下 | 支払額 × 1/4 ＋ 20,000円 |
| 80,000円超 | 一律 40,000円 |

**旧制度（1区分あたり）**

| 1年間の支払保険料 | 控除額 |
|---|---|
| 25,000円以下 | 全額 |
| 25,000円超 50,000円以下 | 支払額 × 1/2 ＋ 12,500円 |
| 50,000円超 100,000円以下 | 支払額 × 1/4 ＋ 25,000円 |
| 100,000円超 | 一律 50,000円 |

### 上限のルール

- 同じ区分に**新と旧の両方**がある場合は、①旧だけで計算した額（上限5万円）か、②新と旧をそれぞれ計算して足した額（上限4万円）の、有利な方を選べます。
- 3区分を合わせた控除額の上限は**12万円**です。

### 例

一般の新制度で年96,000円、個人年金の旧制度で年60,000円、介護医療の新制度で年30,000円を払った人。

| 区分 | 計算 | 控除額 |
|---|---|---|
| 一般（新） | 80,000円超 | 40,000円 |
| 個人年金（旧） | 60,000 × 1/4 ＋ 25,000 | 40,000円 |
| 介護医療（新） | 30,000 × 1/2 ＋ 10,000 | 25,000円 |
| 合計 | 105,000円（12万円以下） | **105,000円** |

## 2. 地震保険料控除：旧長期損害保険と合わせて5万円まで

| 区分 | 1年間の支払保険料 | 控除額 |
|---|---|---|
| 地震保険料 | 50,000円以下 | 全額 |
|  | 50,000円超 | 一律 50,000円 |
| 旧長期損害保険料（平成18年末までの10年以上の契約など） | 10,000円以下 | 全額 |
|  | 10,000円超 20,000円以下 | 支払額 × 1/2 ＋ 5,000円 |
|  | 20,000円超 | 一律 15,000円 |

両方ある場合は合計で**5万円**が上限です。1つの契約が両方に当たるときは、どちらか一方を選びます。火災保険だけの部分は対象になりません。

---

## 3. 社会保険料控除：払った分の全額

健康保険・厚生年金・雇用保険のように**給与から引かれた分は、勤務先がすでに把握している**ので、この申告書には書きません。書くのは自分で払った分です。

- **国民年金保険料**：日本年金機構の控除証明書を添付します。
- **国民健康保険料・介護保険料・後期高齢者医療保険料**：証明書の添付は不要ですが、金額を書きます。
- **家族の分を本人が払った場合**：生計を一にする配偶者や親族の保険料を本人が払ったなら、本人の控除にできます。たとえば学生の子の国民年金保険料を親が払った場合です。

控除額は**支払った金額の全額**で、上限はありません。

---

## 4. 小規模企業共済等掛金控除：iDeCoは全額

個人型確定拠出年金（iDeCo）の掛金を**自分の口座から払っている人**は、国民年金基金連合会の「小規模企業共済等掛金払込証明書」の金額を書きます。こちらも全額が控除されます。給与天引きで払っている場合は、勤務先が把握しているので書きません。

## 5. 提出前のチェックリスト

- [ ] 生命保険の控除証明書を区分（一般・介護医療・個人年金）と新旧ごとに分けた
- [ ] 同じ区分に新旧がある場合、有利な計算を選んだ
- [ ] 生命保険料の合計控除額が12万円以下になっている
- [ ] 地震保険と旧長期損害保険の合計が5万円以下になっている
- [ ] 国民年金保険料の控除証明書を添付した
- [ ] 家族の保険料を自分で払った分を書いた
- [ ] iDeCoを口座振替で払っている場合、払込証明書の金額を書いた

書類の出し忘れや計算の誤りに後で気づいた場合は、翌年1月31日までなら勤務先で再調整してもらえることがあります。それを過ぎたら確定申告で直します（[第3章](/ja/japan-year-end-adjustment-ch3/)）。
