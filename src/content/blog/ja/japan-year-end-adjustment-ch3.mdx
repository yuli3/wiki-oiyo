会社員の所得税は、多くの場合12月の年末調整で1年分の精算が終わります。ただし、**年末調整の対象にならない人**や、**年末調整では受けられない控除を使いたい人**は、翌年2月16日から3月15日までの確定申告で手続きをします（還付申告は1月から5年間できます）。この章はその境目を整理します。

<Callout type="note" title="数字の確認について">
- 条件と金額は国税庁タックスアンサー No.1900・No.1120・No.1155 で確認しました（確認日 **2026-11-02**）。
- 個別の判断は勤務先・税務署・税理士にご確認ください。Oiyoは国税庁とは関係ありません。
</Callout>

---

## 1. 確定申告が必要な給与所得者

国税庁 No.1900 は、次のいずれかに当てはまる給与所得者は確定申告が必要としています（申告すれば還付になる人を除く）。

| 条件 | よくある例 |
|---|---|
| 給与の収入金額が **2,000万円を超える** | 年末調整の対象外になります |
| 給与を1か所から受け、給与所得・退職所得以外の所得の合計が **20万円を超える** | 副業の雑所得、不動産所得など |
| 給与を2か所以上から受け、年末調整されなかった給与と各種所得の合計が **20万円を超える** | 掛け持ちのアルバイト（ただし一定の場合は不要） |
| 同族会社の役員で、その会社から貸付金の利子や賃貸料を受け取っている | |
| 災害減免法で源泉徴収の猶予を受けている、源泉徴収義務のない者から給与を受けている など | |

「20万円以下なら申告不要」は**所得税の話**です。住民税は別に申告が必要になることがあるので、お住まいの市区町村に確認してください。

---

## 2. 年末調整では受けられない控除

次の控除は年末調整の申告書には書けません。使いたい場合は確定申告をします。

| 控除 | ポイント |
|---|---|
| **医療費控除** | 支払った医療費 − 保険金などで補てんされる金額 − **10万円**（総所得金額等が200万円未満なら総所得金額等の5%）。上限200万円 |
| **セルフメディケーション税制** | 特定一般用医薬品等の購入費のうち **12,000円を超える部分**、上限 **88,000円**。医療費控除とはどちらか一方を選択 |
| **寄附金控除（ふるさと納税など）** | 寄附額のうち2,000円を超える部分。所得税の控除対象は総所得金額等の40%が上限 |
| **雑損控除** | 災害・盗難などの損失 |
| **住宅借入金等特別控除の1年目** | 2年目以降は年末調整で受けられます |

医療費控除は、本人だけでなく**生計を一にする配偶者や親族のために支払った医療費**も合算できます。支払った年の1月1日から12月31日までの分が対象です。

---

## 3. ふるさと納税のワンストップ特例

確定申告が不要な給与所得者は、**寄附先が5団体以内**であれば、寄附先の自治体に申請するだけで寄附金控除を受けられます（ワンストップ特例）。

- 寄附先が6団体以上になった場合は、確定申告が必要です。
- 医療費控除などのために確定申告をする場合、**ワンストップ特例は無効**になります。ふるさと納税の分も含めて確定申告書に書きます。
- 申請期限は寄附先の案内で確認してください（一般に寄附した翌年の1月10日まで）。

---

## 4. 年末調整を受けたあとに確定申告する流れ

1. 勤務先から**源泉徴収票**を受け取ります（1月ごろ）。
2. 医療費の明細書（医療保険者の医療費通知を使うと記載を簡略化できます）や寄附の受領証明書を用意します。
3. 国税庁の「確定申告書等作成コーナー」で源泉徴収票の金額と追加の控除を入力します。
4. 還付になる場合は、指定した口座に振り込まれます。

年末調整の全体の流れは[第1章](/ja/japan-year-end-adjustment-ch1/)、令和8年分の改正点は[第2章](/ja/japan-year-end-adjustment-ch2/)をご覧ください。
