16種類のMBTI性格タイプを一か所にまとめました。各タイプの別名と主な傾向を確認し、気になるタイプをクリックすると、強み・弱み・仕事・恋愛まで扱う詳しい事典へ移動できます。タイプは4つの気質グループ — 分析家（NT）・外交官（NF）・番人（SJ）・探検家（SP） — に分かれます。

## 分析家タイプ (NT)

| タイプ | 主な傾向 |
|---|---|
| [INTJ 戦略家](https://oiyo.net/ja/mbti/intj/) | 長期的なビジョンと戦略的思考でシステムを設計する、独立心の強い完璧主義者 |
| [INTP 論理学者](https://oiyo.net/ja/mbti/intp/) | 好奇心と論理で概念の根本を掘り下げる理論家 |
| [ENTJ 指揮官](https://oiyo.net/ja/mbti/entj/) | 目標志向のリーダーシップで組織を導く指揮官 |
| [ENTP 討論者](https://oiyo.net/ja/mbti/entp/) | アイデアと議論を楽しむ、機転の利いた革新家 |

## 外交官タイプ (NF)

| タイプ | 主な傾向 |
|---|---|
| [INFJ 提唱者](https://oiyo.net/ja/mbti/infj/) | 洞察と理想で人を助ける、静かな信念の持ち主 |
| [INFP 仲介者](https://oiyo.net/ja/mbti/infp/) | 価値観と誠実さを追求する理想主義的な夢想家 |
| [ENFJ 主人公](https://oiyo.net/ja/mbti/enfj/) | 共感力とカリスマ性で人を導くリーダー |
| [ENFP 運動家](https://oiyo.net/ja/mbti/enfp/) | 情熱と可能性でインスピレーションを与える自由な活動家 |

## 番人タイプ (SJ)

| タイプ | 主な傾向 |
|---|---|
| [ISTJ 現実主義者](https://oiyo.net/ja/mbti/istj/) | 責任感と原則で信頼を築く現実主義者 |
| [ISFJ 擁護者](https://oiyo.net/ja/mbti/isfj/) | 献身と思いやりで周囲を支える温かな守護者 |
| [ESTJ 幹部](https://oiyo.net/ja/mbti/estj/) | 体系と効率で物事をやり遂げる管理者 |
| [ESFJ 領事](https://oiyo.net/ja/mbti/esfj/) | 調和と奉仕で共同体を支える社交家 |

## 探検家タイプ (SP)

| タイプ | 主な傾向 |
|---|---|
| [ISTP 巨匠](https://oiyo.net/ja/mbti/istp/) | 手先の感覚と論理で問題を解決する万能な実践家 |
| [ISFP 冒険家](https://oiyo.net/ja/mbti/isfp/) | 感覚と自由を愛する芸術的な冒険家 |
| [ESTP 起業家](https://oiyo.net/ja/mbti/estp/) | 行動力と瞬発力で現場を駆け回る活動家 |
| [ESFP エンターテイナー](https://oiyo.net/ja/mbti/esfp/) | 楽しさとエネルギーで場を明るくするエンターテイナー |
