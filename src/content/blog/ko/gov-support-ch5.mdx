# Chapter 5. 국가·지방 지원사업 구분 정리

정부 지원사업은 크게 **중앙정부(국가)** 가 운영하는 사업과 **지방자치단체(시·도·군·구)** 가 운영하는 사업으로 나뉩니다. 같은 지원 유형이라도 중앙정부 사업은 전국 어디서나 동일한 기준이 적용되고, 지자체 사업은 지역별로 내용이 크게 다릅니다. 두 가지를 모두 파악해야 놓치는 혜택이 없습니다.

<Callout>
**통합 조회 창구**: **복지로(https://www.bokjiro.go.kr)** 의 '복지서비스 모의계산'과 **정부24(https://www.gov.kr)** 의 '내게 맞는 서비스 찾기'를 이용하면 중앙+지방 사업을 한 번에 조회할 수 있습니다.
</Callout>

## 4. 지자체 지원사업 찾는 방법 (실전)

### 방법 1: 복지로 맞춤형 검색

1. 복지로(https://www.bokjiro.go.kr) 접속
2. 상단 '복지서비스 모의계산' 클릭
3. 가구 정보 입력 → 수급 가능 서비스 목록 확인
4. 지역 선택 시 해당 지자체 사업도 포함됨

### 방법 2: 정부24 내게 맞는 서비스

1. 정부24(https://www.gov.kr) 접속
2. '내게 맞는 서비스 찾기' → 생애주기/관심 주제 선택
3. 중앙+지방 사업 통합 목록 확인

### 방법 3: 주민센터 복지 상담

읍·면·동 주민센터의 **사회복지 담당자**에게 직접 문의하면 해당 지역에서 받을 수 있는 모든 지원사업을 안내받을 수 있습니다. "복지 플래너"가 있는 센터도 있습니다.

### 방법 4: 지자체 SNS·홈페이지

- 거주 지역 시청·군청·구청 공식 홈페이지 → '복지/지원사업' 메뉴
- 지자체 공식 인스타그램·유튜브에서도 새 사업 발표
