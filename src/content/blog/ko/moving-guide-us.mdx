미국에서의 이사는 한국과 다른 독특한 절차들이 있습니다. 주(State)마다 법이 다르고, 신용 점수(Credit Score)가 임대 계약에 큰 영향을 미치며, 주소 변경을 여러 기관에 개별 신고해야 합니다. 미국 거주 중이거나 미국으로 이주를 준비하는 분들을 위해 핵심 절차를 정리했습니다.

---

## 1. 이사 전 — 집 구하기와 계약

### 주거 형태 이해
- **Apartment**: 관리인(Landlord)이 있는 공동주택. 월세(Monthly Rent)가 일반적
- **House Rent**: 개인 집주인에게 임대. 마당·차고 포함 많음
- **Studio / 1BR / 2BR**: 방 개수에 따라 Studio(원룸), 1 Bedroom, 2 Bedroom으로 구분

### 임대차 계약 시 확인 사항
- **Lease Agreement**: 계약 기간(보통 12개월), 월세, 보증금(Security Deposit) 명확 확인
- **Security Deposit**: 통상 월세 1~2개월치. 주 법률로 상한 규정 있음
- **Pet Policy**: 반려동물 허용 여부 및 Pet Deposit 별도 확인
- **Subletting 조항**: 재임대 금지 여부 확인
- **Early Termination Fee**: 조기 해지 시 위약금 조항 확인
- **Move-in Checklist**: 입주 시 집 상태(기존 파손) 서면 기록 → 퇴거 시 분쟁 예방

### 신용 점수(Credit Score) 없는 경우
- 미국 초기 거주자는 신용 이력이 없어 임대가 거절될 수 있음
- 해결책: 더 높은 보증금 제안, 보증인(Co-signer) 확보, 첫 몇 달 선불 제안
- 한인 타운·코리안 커뮤니티 앱(Karrot 등) 활용

---

## 2. 이사 준비 — 이사업체와 짐 정리

### 이사업체 선정
- **Full-Service Moving Company**: 포장·운반·설치까지 (비용 높음)
- **Moving Truck Rental**: U-Haul, Penske, Budget 등 직접 운전 (저렴)
- **Portable Storage Container**: PODS, U-Box 등 — 장거리·보관 필요 시
- 주(State) 간 이사 시 **Licensed & Insured** 업체인지 [FMCSA 확인](https://www.fmcsa.dot.gov/protect-your-move)

### 장거리 이사(Cross-State) 추가 고려
- 자동차 운반 서비스(Auto Transport) 별도 비용 발생
- 이사 짐 부피·무게에 따라 비용 산정 → 최소 3곳 견적 비교
- 팁(Tip): 이사 완료 후 팀당 $20~50 수준 (소규모 이사 기준)

## 3. 이사 당일 — 현장 확인

### 출발지 체크리스트
- [ ] Walk-through: 집 전체 점검, 파손 여부 사진/영상 촬영
- [ ] 유틸리티(전기·가스·인터넷) 최종 미터기 촬영
- [ ] 열쇠·주차권·접근카드 반납
- [ ] 우편함 비우기
- [ ] 세탁기 드레인 호스 분리 확인

### 도착지 체크리스트
- [ ] Move-in Checklist 양식에 기존 파손 상태 기록 후 서명 (집주인과 공유)
- [ ] 유틸리티 작동 확인 (전기·수도·가스·난방/냉방)
- [ ] 인터넷 설치 예약 확인 (미리 ISP에 신청해두기)
- [ ] 스모크 디텍터·CO 감지기 작동 확인 (법적 의무)

## 4. 이사 후 — 미국 주소 변경 필수 목록

### ① USPS 우편물 전달 신청 (Forward Mail)
- [USPS 공식 사이트](https://moversguide.usps.com) → $1.10 본인 인증 후 주소 변경
- Forward 기간: 최대 12개월 (기간 내 새 주소로 우편물 전달)
- **중요**: 기존 발신인에게 새 주소 직접 통보도 병행

### ② 운전면허증(Driver's License) 주소 변경
- 각 주(State) DMV(Department of Motor Vehicles)에서 처리
- 주마다 기한 다름: 캘리포니아 10일, 텍사스 30일, 뉴욕 10일
- 대부분 온라인 신청 가능: [각 주 DMV 링크](https://www.dmv.org)
- **주 간 이사 시**: 새 주 운전면허 재발급 필요 (기한 내)

### ③ 차량 등록(Vehicle Registration) 변경
- 주 간 이사 시 새 주에서 재등록 (기간 보통 30~90일)
- 차량 검사(Smog/Emissions Test) 필요한 주 있음
- 보험사에도 새 주소 통보 (보험료 변동 가능)

### ④ IRS(국세청) 주소 변경
- Form 8822 작성 후 우편 발송: [IRS Form 8822](https://www.irs.gov/forms-pubs/about-form-8822)
- 온라인 변경은 불가 (우편만 가능)
- 세금 환급(Refund)이 있는 경우 늦으면 수표(Check)가 구주소로 발송됨

### ⑤ 소셜시큐리티(SSA) 주소 변경
- [SSA 온라인](https://www.ssa.gov/myaccount) my Social Security 계정에서 변경
- 베네핏 수령자라면 반드시 업데이트

### ⑥ 투표인 등록(Voter Registration) 변경
- [Vote.gov](https://vote.gov) → 새 주소로 유권자 등록 갱신
- 이전 등록은 자동 해제되지 않으므로 직접 갱신 필요

### ⑦ 금융기관 주소 변경
- 은행·크레딧 카드·투자 계좌 개별 업데이트
- 미국 은행들은 주소 불일치 시 카드 발급·배송 문제 발생

---

## 5. 보증금 반환

- 퇴거 후 각 주마다 반환 기한 다름 (캘리포니아 21일, 뉴욕 14일 등)
- **Security Deposit Deductions**: 청소비·수리비 공제 가능하나 근거 서류 제공 의무
- 분쟁 시: 각 주 Small Claims Court에 소송 가능 (변호사 불필요, 신청비 저렴)
