**工作价值观（work values）**是指一个人在工作内容、环境、关系、回报、自主性等方面重视哪些条件。兴趣更接近“我想做什么”，工作价值观则更接近“我想在什么条件下工作”。

工作价值观不测量能力、性格、资质或职业资格。某项价值较高，也不能证明一个人适合某种职业。它只是职业探索中的一类参考信息。

## O*NET与CareerOneStop的六类工作价值

美国劳工部O*NET数据体系和CareerOneStop Work Values Matcher使用以下六类价值。

| 价值 | 一般含义 |
|---|---|
| 成就（Achievement） | 能发挥能力并获得成就感的工作 |
| 独立（Independence） | 能独立决策和尝试自己想法的工作 |
| 认可（Recognition） | 有晋升、领导和获得认可机会的工作 |
| 关系（Relationships） | 能帮助他人并维持友好、合乎伦理关系的工作 |
| 支持（Support） | 管理者和组织公平支持员工的工作 |
| 工作条件（Working Conditions） | 具备稳定、报酬、安全、多样性等偏好条件的工作 |

目前的CareerOneStop Work Values Matcher是一项**将20条理想工作陈述按重要程度分类的卡片排序活动**，并把选择连接到六类价值。它以O*NET Work Importance Locator（WIL）为基础。不过，O*NET WIL本身已于**2024年6月3日退役**，现仅保留历史与研究资料。

## OIYO活动与官方体系的区别

OIYO另行设计了一项用于自我反思的**18题、六维活动**。

| 项目 | O*NET／CareerOneStop | OIYO |
|---|---|---|
| 维度 | 成就、独立、认可、关系、支持、工作条件 | 稳定、成就、自主、贡献、创造、认可 |
| 形式 | CareerOneStop的20卡片排序 | 回答18道题 |
| 定位 | 基于O*NET的公共职业探索框架 | OIYO原创自我反思活动 |

名称相似并不代表两个体系相同。OIYO活动不是官方O*NET WIL，也不宣称是经过心理测量效度验证或常模化的测验。不能直接换算两套分数，也不应只凭结果判断职业匹配度。
